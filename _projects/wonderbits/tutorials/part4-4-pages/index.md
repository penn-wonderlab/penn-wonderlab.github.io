Everything in the clips so far has happened on a single page. A space can hold as many as a class needs, and each one is a separate working surface rather than a section of the same canvas.

## In this clip

- The page menu, next to the space name, listing every page in the space
- Adding a page when the class starts something new — it opens empty
- Renaming a page to describe its focus
- Switching between pages, each keeping its own canvas, views, groups and levels
- Reordering pages so the menu matches how the unit runs
- Adding, renaming and reordering are manager moves, like rising above

> **Try it:** If your space is starting to hold two different conversations, that's usually a second page waiting to happen. Split them and see whether each gets easier to read.
