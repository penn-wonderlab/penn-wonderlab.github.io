## In this clip

- Choosing **Class Space** rather than Design Space — only a class space carries an invite link
- Naming it after the course, and writing the description a student reads on arrival
- The invite link and its six-character code — send either one
- Students joining as themselves, with Google, Microsoft or an email address, and appearing in the members list
- Making a co-teacher or teaching assistant a **manager**, in one click
- What a manager gets — settings, curation, analytics — and what stays yours: archiving, deleting, and appointing anyone else

> **Try it:** Make the space before you need it and send the link out with the first reading. A class that already has somewhere to put its thinking tends to start putting things there.
