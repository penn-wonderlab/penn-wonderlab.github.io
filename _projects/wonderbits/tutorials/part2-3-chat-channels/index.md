The canvas is for ideas. The talk around them lives beside it, in channels. Everything there is public to the class by design, and it arrives in real time.

## In this clip

- Opening chat from the toolbar, and picking a channel to drop into
- Every channel is public — the class can read and join any of them
- Typing **@** to pull someone in, and picking them from the list so the mention resolves
- Starting a channel from a tag, so a conversation has one topic rather than everything at once

> **Try it:** Next time you'd have written a long comment on a card, ask in the channel instead and mention the person you're asking. Comments stick to one idea; a channel is where a question can find whoever knows.
